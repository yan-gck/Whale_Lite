        怎么把补充包放进手机（两种办法）
        
    
          
  1. 数据线：把 .lppack 文件拖到上面那个目录里，回到这里点「重新扫描」。
    2. 
          
  2. 在手机里导入：点右上角「导入 .lppack」选文件，App 会自己复制进去；
              装好之后原始文件就可以删掉了，能省一倍空间。
    3. 
        

        
补充包不用解压，App 直接从里面读，也不占额外空间。

      


      

        进阶：为什么会有补充包 / 怎么自己做一个
        

          安装包（APK）单个文件有 2 GB 的格式上限，全部素材装不进去，
          所以把「随时要用的前端 + 少量演示课」放进安装包，
          把雅思/六级这种大批素材单独打成补充包。补充包就是普通 ZIP，
          用解压软件也能打开看。
        

        
在电脑上（项目目录里）可以自己打包任意素材目录：

        
node tools/build-pack.js --list            # 看看有哪些素材目录可打包
node tools/build-pack.js --set=IELTS-剑桥真题 --out=雅思听力补充包.lppack
node tools/pack-info.js 雅思听力补充包.lppack --verify   # 打包后校验一下

        

          打包好的文件会出现在「Whale-Lite-手机版」文件夹里，拷进手机即可。
          想加入自己的听力材料，把音频和同名 .lrc 放进项目的
          audio/ 目录即可（格式见 docs/format.md）。
